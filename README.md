# 華記蜜餞創始店 新竹物流 Excel轉換工具

把網路商店匯出的訂單 Excel（.xlsx / .xls），一鍵轉成新竹物流的宅配匯入格式。

**網址：** https://dwlin321-username.github.io/excel-change/

## 隱私

- 檔案只在你自己的瀏覽器裡處理，**不會上傳到任何伺服器**
- 網頁設有 Content-Security-Policy（`connect-src 'none'`），瀏覽器會直接禁止本頁發出任何網路連線
- Excel 函式庫（SheetJS 0.20.3、ExcelJS 4.4.0）放在本 repo 的 `vendor/`，不從外部 CDN 載入
- 沒有任何追蹤或統計程式碼
- `.gitignore` 已排除 `*.xlsx` / `*.xls` / `*.csv`，避免真實顧客資料被誤傳進這個公開 repo

## 轉換規則

| 輸出欄位 | 規則 |
|---|---|
| 訂單號碼、電話二 | 空白 |
| 收貨人姓名 | 去掉結尾「先生／小姐」；去掉後只剩 1 個字就保留原樣（如「林小姐」）；「鄭君怡 鄭先生」→「鄭君怡」。含數字、英文、符號、空白或「收」字 → 原樣保留，後面加上紅字「（建議檢查）」 |
| 收貨人電話、地址 | 原樣複製（去頭尾空白），電話以文字格式儲存 |
| 件數 | 一律 1 |
| 重量 | 商品總數 ≥ 100 → 20，否則 10；讀不到數量 → 10 並標**紅字** |
| 託運備註 | 原訂單備註原樣複製（保留換行）。含「贈品」，或排除「送達、送到、配送、寄送、送貨、運送」後仍含「送」→ 原樣保留，後面加上紅字「（建議刪除）」。但只要含「配送」或「運送」（即使同時有贈品）→ 原樣保留，不加提醒 |
| 代收貨款 | 付款方式為「貨到付款」才填，總計轉成數字（`NT$2,500` → `2500`）；讀不到金額 → 保留原文並標**紅字** |

其他：
- 只讀第一個工作表，依標題名稱找欄位（欄位順序變動不影響）
- A 欄出現含「郵局」的列（例如「寄郵局」），該列以下全部排除
- 空白列、缺收貨人姓名的列略過；維持原檔順序
- 輸出格式比照物流匯入範本（工作表 `hungsongV1`、新細明體 12、欄寬、框線；標題列的「必填」「長度限制」「限數字」等說明為紅字）
- 匯入物流系統前，請先人工處理標有「（建議檢查）」「（建議刪除）」的儲存格，並刪掉這些提醒文字
- 檔名：`原檔名_已編輯.xlsx`

## 專案結構

```
index.html            頁面
css/style.css         樣式
js/convert.js         轉換規則（純邏輯）
js/workbook.js        Excel 讀取與輸出格式
js/app.js             畫面流程
vendor/               SheetJS、ExcelJS
tests/                自動測試（只使用虛構資料）
.github/workflows/    推送到 main 後自動測試並發布
```

## 開發

```bash
npm test
```

在本機預覽：

```bash
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。

推送到 `main` 後，GitHub Actions 會先執行測試，**測試全部通過才會更新網站**。
